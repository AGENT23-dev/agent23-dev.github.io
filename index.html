Personal automation client

Hermes Agent — Mac mini de DIY23

A single-user assistant that works with the Google account of the person who runs it.

What this application is

Hermes Agent is a private automation client installed and operated by an individual (the "operator") on a single Apple Mac mini computer that the operator owns and keeps at home. There is no public sign-up, no multi-tenant service, no server-side account system and no other users. It is the operator's own tool for their own data.

The client connects to exactly one Google account — the operator's — after the operator grants permission through Google's standard OAuth 2.0 consent screen. It cannot access, list or act on any other person's Google account, and it has no mechanism to do so.

What it does with Google services

ServiceUse
GmailSearch and read the operator's messages, send mail on the operator's instruction, apply labels.
Google DriveFind, read, upload, download, create folders, rename, trash files, and share a file with a recipient the operator names.
Google DocsRead documents, create documents, append text to documents.
Google SheetsRead cell ranges, create spreadsheets, write and append rows.
Google CalendarList upcoming events, create and delete events.
ContactsRead the operator's own contact list to resolve names to addresses.

Every action is initiated by the operator in a conversation with the assistant. The client sends nothing to third parties, contains no advertising, and never resells or redistributes Google user data.

One account, one machine. The OAuth tokens are stored in a single file on the operator's own computer with owner-only permissions. No copy of that token, and no copy of Google user data, is kept on any server operated by this project — there is no such server.

Your control

Access is granted and withdrawn entirely from the Google account side. The operator can revoke the application's access at any time at myaccount.google.com/permissions, which invalidates the stored token immediately.
